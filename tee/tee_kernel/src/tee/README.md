# tee

rust implement for tee core

## arch

`hygon_csv_bindings.rs` is auto generated by repo https://gitee.com/kylinyubo/rust-csv-guest-module-tools.

Do not hand-edit the bindings. Attestation report types (`csv_attestation_report_t`,
`csv3_attestation_report_ext`, and related structs) must be accessed only through
`arch/x86_64/hygon_csv.rs`, which enforces buffer-length and field-offset checks
before reading hypercall output.

ABI `reserved` fields (for example the 716-byte field in `csv3_attestation_report_ext`)
are layout padding or vendor-reserved space. They are not parsed as TEE payload and
must not be filled from external input.
