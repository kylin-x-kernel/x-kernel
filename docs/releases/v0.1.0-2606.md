## X-Kernel v0.1.0-2606 Release Notes

### 1. 版本摘要

`v0.1.0-2606` 是 X-Kernel 的首个正式版本。

该版本确立了项目的基础发布基线，提供多架构单体 Rust 内核的核心能力，
覆盖内存管理、进程与任务调度、文件系统、网络、设备驱动和 TEE 支持，
并形成了统一的 Kconfig/Makefile 构建与运行流程。

### 2. 支持的架构与平台

当前版本支持以下架构：

- `x86_64`
- `aarch64`
- `riscv64`
- `loongarch64`

当前版本支持以下平台与运行环境：

- `QEMU`
- `Hygon CSV Environment`
- `Linux kylin-x Pkvm Virtual Machine`

### 3. 主要能力

当前版本包含以下核心能力：

- 多架构内核启动与基础运行支持
- 基于 Kconfig 的配置体系和基于 `make` 的统一构建流程
- 进程、线程、定时器、信号、futex 与 POSIX 兼容基础设施
- 虚拟内存与地址空间管理
- VFS 与多类文件系统支持
- 网络子系统与基础 TCP/IP 能力
- TEE（Trusted Execution Environment）支持
- 面向 QEMU 和多平台的镜像生成与运行支持

### 4. 版本内重要工作

在 `v0.1.0-2606` 版本周期内，主线完成了以下代表性工作：

- 引入并持续完善 TEE 相关能力，包括多进程安全存储、TA 生命周期清理和
  TA 签名与加载路径加固
- 以 RustCrypto 方案替换旧加密实现路径，完善 ECC、SM2、RSA 等能力
- 增强文件系统、VFS、路径校验和随机设备的稳定性与安全性
- 完善网络能力，包括 TCP 发送路径和自动 ICMP echo reply 支持
- 完善 `execve`、`waitpid`、`clock_nanosleep` 等核心系统行为
- 加强 AArch64 相关运行稳定性，包括 ASID 与 TLB 切换逻辑修复
- 持续清理 `unsafe`、补充单元测试并强化主机侧构建工具输入校验

### 5. 构建与运行

发布版本仍然使用项目标准流程构建与运行。

准备配置：

```bash
cp platforms/aarch64-qemu-virt/defconfig .config
make defconfig
```

常用命令：

```bash
make build
make clippy
make run
make UNITTEST=y run
make unittest
```

### 6. 已知限制

当前版本是首个正式版本，仍以能力建设和稳定性收敛为主，已知限制包括：

- 不同架构和平台的能力成熟度仍存在差异
- 部分子系统仍在持续重构与边界收敛阶段
- 一些高级特性、性能优化和更完整的兼容性覆盖仍在后续版本推进

### 7. 升级与分支维护说明

- `release/2606` 分支维护 `0.1.x` 稳定版本线
- 后续问题修复将在该分支上递增补丁版本，例如 `v0.1.1-2606`
- `main` 分支在 `release/2606` 切出后应前进到下一季度开发版本，例如 `0.2.0-dev`

### 8. 后续计划

后续版本将继续围绕以下方向推进：

- 提升多架构稳定性与一致性
- 完善 TEE、文件系统、网络与进程子系统能力
- 继续收敛模块边界、补全文档和测试覆盖
- 为下一季度版本 `v0.2.0-2609` 做主线能力准备
