# 语言项

本节涵盖了针对特定 Rust 语言构造的约定。每个页面通过可操作的指南来阐述一个类别。

- **[变量、表达式与语句](variables-expressions-and-statements.md)** —  
  解释变量、块表达式以及带检查的算术运算。
- **[函数与方法](functions-and-methods.md)** —  
  关于嵌套控制、函数专注性以及避免布尔类型参数。

- **[类型与 trait](types-and-traits.md)** —  
  类型级不变量、封闭集合建模以及字段封装。
- **[注释与文档](comments-and-documentation.md)** —  
  Rustdoc 约定、标点/可读性以及模块文档。
- **[unsafe 相关](unsafety.md)** —  
  `// SAFETY:` 注释、`# Safety` 段落以及模块边界审查。
- **[模块与 crate](modules-and-crates.md)** —  
  可见性与依赖策略。

- **[宏与属性](macros-and-attributes.md)** —  
  Lint 抑制的作用域、
  死代码预期、
  以及宏使用的克制。
