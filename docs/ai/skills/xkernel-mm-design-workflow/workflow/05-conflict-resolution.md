# Phase 5: Conflict Resolution

## Owner

Design Arbiter

## Purpose

Turn review findings into explicit decisions and phase boundaries.

## Required Output

Use `templates/arbiter-decision-table-template.md`.

## Required Classes

- `Must Preserve Now`
- `Preserve Later`
- `Explicitly Dropped`

## Rules

- No silent merging.
- No "decide later" for critical core-model issues.
- If a topic is still too broad, split it and stop the workflow.

## Exit Criteria

A decision table exists and critical conflicts are classified.
