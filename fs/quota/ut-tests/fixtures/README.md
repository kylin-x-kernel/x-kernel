# v2 quota interoperability fixture

`e2fsprogs-v2-user.bin` is the unmodified user-quota inode generated by
e2fsprogs 1.47.2 on an otherwise empty 64 MiB ext4 image. It contains a
revision-one header, one ID-zero record with two inodes and 13312 used bytes,
and independently generated radix-tree/data-block metadata.

Regenerate with:

```sh
truncate -s 64M /tmp/quota-format-image.ext4
mkfs.ext4 -q -F -O quota -E quotatype=usrquota:grpquota:prjquota /tmp/quota-format-image.ext4
debugfs -R 'dump <3> /tmp/e2fsprogs-v2-user.bin' /tmp/quota-format-image.ext4
```

The image UUID and creation time do not occur in the dumped quota file.
